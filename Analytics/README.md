# Аналитика Poki

Выгрузки событий `measure` из дашборда Poki по версиям игры. Нужны, чтобы сравнивать версии между собой.

- Папка на версию: `Analytics/v<версия>/`, версия совпадает с тегом релиза.
- Файлы переименовываем при сохранении: `v<версия>_<тип>.csv`, где тип это `progress-events`, `other-events` или `interaction-events` (так их называет Poki). Скачанные `... (5).csv` кладём только в таком виде.
- Рядом `analysis.md` с выводами по этой версии и числами, на которые потом смотреть при сравнении.
- Имена событий не меняем (см. `RoundEvents` и CLAUDE.md), иначе версии не сравнить. Новые события добавляем; устаревшее можно снять, отметив версию в `RoundEvents` и в заголовке таблицы отчёта, а таблицу оставив для старых версий (после v0.14.1 сняты `out-cause`, `boosts`, `lobby-shown`, `coins`).
- Время сессии и engaged Poki показывает только на Player Fit Test; после v0.14.1 игра шлёт свои `session / time-Nm / reached` и `play-Nm` (таблица «Время сессии» в отчёте).
